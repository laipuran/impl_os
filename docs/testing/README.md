# 检查与测试状态

## 当前入口

| 命令 | 能证明什么 |
|---|---|
| 容器内 `just check` | Rust 格式、双架构 Clippy；不是功能测试 |
| 容器内 `just build` / `make all` | 生成两个架构 ELF |
| 宿主 `just judge-build` | 原始比赛镜像禁网、独立 Cargo 缓存构建；不运行内核 |
| 容器内 `just run-rv` / `just run-la` | 手动观察启动与退出行为 |

项目不再包含 Python 开发工具或它们的单元测试，也没有自动化启动/评分脚本。当前没有真实的自动化内核测试，不能报告“若干项测试通过”来代替内核功能验证。

## 已有实测

日期：2026-10-26。[容器实测记录](container-validation.md)保留历史验证证据，不能把其中已删除的自动工具当作当前可用命令。

- 指定原始镜像：QEMU 10.0.2、OpenSBI 1.5.1、固定 Rust nightly。
- 原始镜像中曾完成断网、过滤隐藏文件后的双架构构建与启动。
- RISC-V 能输出启动日志并正常关机；LoongArch 能输出启动日志但关机未实现。
- 从未运行官方用户态测试，没有通过率或分数。后续接入计划见[测试矩阵](test-matrix.md)。
