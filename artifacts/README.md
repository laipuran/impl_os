# 本地测试资源与日志目录（`artifacts/`）

本目录用于存放本地调试所需的测试镜像、串口日志或故障注入临时文件。除本说明文件外，目录下的所有内容均被 `.gitignore` 忽略，不会提交到 Git 仓库。

推荐按如下结构管理本地文件：

```text
artifacts/
  test-images/   # 官方测例磁盘镜像（传入 QEMU 前需解压为原始 EXT4 镜像）
  logs/          # 串口输出日志、QEMU 导出的 dtb 等调试产物
```

## 注意事项

1. **记录镜像版本：** 下载或更新官方测试镜像时，建议顺手记录镜像来源、对应的测例仓库 commit 以及 SHA256 校验值，方便团队对齐测试基准。
2. **解压后挂载：** QEMU 的 `raw` 格式块设备驱动需要解压后的 EXT4 镜像文件，不能直接挂载 `.gz` 或 `.xz` 压缩包。
3. **保持构建独立：** 比赛要求的内核产物（`kernel-rv`、`kernel-la`）直接生成在仓库根目录，评测构建过程也不会读取 `artifacts/`。请勿将编译依赖的文件放在此处。
